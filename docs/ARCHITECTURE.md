# Architecture

## Distribution model

- `dist/VFE-Corel-Production-Tools-27.gms` is the ready-to-load CorelDRAW macro project.
- `src/VFE_CorelProductionTools27.bas` is the main engine and public runtime API.
- `src/VFE_UI_Installer.bas` is a build-time utility that creates the UserForms in a target GMS project.

## Runtime components

### Main module

`VFE_CorelProductionTools27` contains:

- launcher entry point;
- visual-interface API;
- dimension engine;
- export engine;
- page preparation;
- recursive text-to-curves handling;
- filename resolution;
- profiles and settings;
- progress/cancellation;
- logging and file utilities.

### UserForms

- `frmVFELauncher`
- `frmVFEDimensionTool`
- `frmVFEExportWorkflow`

The UserForms are generated by the installer and saved inside the GMS. The final end-user GMS does not require the installer module to run.

## Primary public entry point

```text
VFE_CorelProductionTools27.VFE_CorelProductionTools27
```

## Build-time public entry point

```text
VFE_UI_Installer.VFE_InstallVisualInterface
```

## Data and profiles

Export profiles use VBA/application settings associated with the current Windows user. Profile portability between machines is not guaranteed unless explicitly implemented in a future release.
