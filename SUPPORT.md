# Support

Use the repository's issue tracker for reproducible bugs and documentation problems. Do not attach confidential customer files publicly.

A useful report includes:

- CorelDRAW version and build;
- Windows version;
- VFE release version;
- workflow/profile settings;
- exact steps;
- screenshot and complete error message;
- export log;
- sanitized sample document, when permitted.

Support, response times, updates, and compatibility fixes are not guaranteed unless covered by a separate written agreement.
